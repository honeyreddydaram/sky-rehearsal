    Terrain & buildings

    Use a Cesium ion read-only token with access to World Terrain and OSM Buildings. It is used only for this tab session and sent to Cesium to load these assets. Building coverage and detail vary by location.

    Experimental: loads Google Photorealistic 3D Tiles through Cesium ion using the token above, instead of World Terrain. Google’s terms for this asset require hiding other imagery, terrain, and OSM buildings while it’s on, so this does that automatically; Google’s own credits stay visible below the map. Needs a token with the geocode scope — your account’s default ion token has this, but a token you scoped down to specific assets (as suggested above for World Terrain) usually won’t, and Google 3D will fail to load with that one. Not verified end-to-end in development — try it and report back if something looks wrong.

    Bring your flight profile

    Import altitude and true airspeed schedules from your instructor or a prepared flight recording.

    Use route progress 0–1, altitude in feet with an explicit reference, and true airspeed in knots. MSL heights also need a local geoid offset to position them in Cesium. Imported data remains on this browser; it does not certify the route.

    Optional callouts can include your instructor’s turn and descent instructions. The example file contains demo values, not an actual flight profile.
